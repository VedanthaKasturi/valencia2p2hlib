Points to raise with Joanna

  • decided
    Q per channel. The branch uses S2p for every ν event and S2n for every ν̄ event. By charge conservation the dominant channels (ν→pp, ν̄→nn) leave the (Z−1, N−1) nucleus, so Eq. (10) of PRC 111 gives Spn; S2n fits ν→np and S2p fits ν̄→np. The legacy C12 value 27.41 MeV is Spn. Kept as delivered for these tests. Size: C12 ν̄ 31.84 vs 27.41; O18 ν̄ 12.19 vs 21.83; Ca40 ν 14.71 vs 21.41 MeV.
  • check
    Interference terms in the np and pn channels look swapped. In the event record line 1 is the nucleon with hole energy E_nuc and momentum transfer q−k. The direct terms put line 1 = n in np and line 1 = p in pn. Interference term tr3_mu tr2_nu has line 1 n→p but is added to np; tr2_mu tr3_nu has line 1 n→n but is added to pn. Inherited from the old code. Cross sections are unaffected; it only swaps which outgoing nucleon is the proton for the interference part, about 5% of np and 2.5% of pn (under 1% of the total).
  • note
    FERMI is now off in every mode. The old main.cc set FERMI=true only in the fixed-energy and flat-range event modes; the flux-weighted and total modes had it off. Turning it off is the PRC 111 prescription (“remove everywhere the constant term −kF2/2M”) and, together with the interference fix below, raises C12 and O16 ν by 4–11% across Eν at fixed Q. Older event samples were therefore not all the same model.
  • fixed
    Interference normalisation bug in the old code. The old first-bubble lower limit reused the second bubble’s Pauli bound (EF−Eπ instead of EF−(ω−Eπ)). The branch’s bubble_limits() fixes it; effect −0.8% on np.
  • note
    Fermi-level mismatch with FERMI off. The Valencia QE model corrects the p/n Fermi-level difference with q0 → q0 − (Q − QLFG(r)) (Nieves, Amaro, Valverde 2004, Eq. 43). The 2p2h branch has no such term; instead it clamps the π− bubble’s spurious emission piece. The clamp acts only for ν̄, only for Eπ < EFn−EFp (≈2 MeV in Ar40, ≈7 MeV in Pb208), and touches 0.27% (Ar40) to 1.4% (Pb208) of |w|. This choice affects the size of the asymmetric effect shown in §4 (figure K).
  • ask
    Numerical Fig. 8 curves. The quoted band edges at 1 GeV are reproduced to 1–2%. Below 1 GeV the comparison relies on reading the plot by eye; for ν̄ the by-eye central curve sits 10–20% above ours at 0.6–0.9 GeV, but that reading is internally inconsistent with the band (see §2). The numbers behind Fig. 8 would settle it.
  • note
    Total-σ modes reuse nr_d as both the number of energy steps and the statistics multiplier, and overwrite it above 1 GeV, which breaks energy scans that cross 1 GeV. Calling them with emin = emax works and gives repeated independent estimates.
Reminder for the reconstruction code. ν and ν̄ now carry different Q for the same nucleus (C12: 27.19 vs 31.84 MeV; O18: 29.06 vs 12.19). The full kinematic reconstruction of the outgoing nucleons must read Q from the run (constants[4] in the output file) and treat ν and ν̄ separately. Your own paper (arXiv:2603.28314) used Snp = 27.41 MeV for C12.

1 · Build and regression

Both codes were run with the same RNG seed and the same Q, so the events are identical and only the code differs. Neutrinos only: the old code cannot save antineutrino events.

Joanna’s branch is 4–11% higher across Eν (7.4% flux-averaged) for both C12 and O16. Two changes in her branch account for all of it: FERMI is off (the old code had it on in this mode), and her new bubble_limits() corrects the hole-energy range of the interference term. Applying both to a scratch copy of the old code reproduces her branch bit for bit.

2 · Antineutrinos

Exact symmetry test of the hadron tensor

Charge symmetry fixes the answer without reference to any paper. In N = Z matter the ν̄ hadron tensor for nn, pn and np must equal the ν tensor for pp, np and pn respectively, component by component, including Im A12 which sources W3; the ν/ν̄ difference lives only in the lepton tensor. In asymmetric matter, ν on (kFp, kFn) = (a, b) must equal ν̄ on (b, a). A small harness calls the branch’s hadron-tensor functions directly at 1000 random kinematic points per test.

Old code vs Joanna’s branch

C12 ν̄ events from the old code (your feature/NuFluxes branch, which stores the ν̄ events) and from Joanna’s branch, both with Q = 27.41 MeV. The old code puts 23% of the 2p2h cross section in nn and 61% in pn; Joanna’s branch gives nn 77% and pn 7.5%. np is 16% in both. The old ν̄ loop filled the nn entry with p→pπ− and the pn entry with n→nπ−; Joanna’s branch fills them with their correct mirror channels. The totals differ by 14% (flux-averaged, 0.15–2 GeV) because the old code also runs with FERMI on in this mode.

Joanna’s branch as delivered

With her ν̄ Q = 31.84 MeV and Re ΣΔ = 0: nn 77%, pn 7.5%, np 15.6%, almost flat in energy. This is the mirror of ν on C12 (pp 80%, np 5.7%, pn 14.4%; Table I of arXiv:2603.28314 gives 80.3–80.5% pp). The small ν/ν̄ offset comes from the opposite sign of W3 in the lepton tensor.

Comparison with PRC 111, Fig. 8

Fig. 8 of Sobczyk & Nieves shows 2p2h including the three-body (3p3h) part; the curves here are 2p2h only, so they sit below the paper by the 3p3h share. The paper is read by eye, except at 1 GeV where the text quotes the band [0.54, 0.71]. In a separate check, adding the generator’s 3p3h reproduces those two band edges to 1–2%.

Channel fractions in all nuclei

Neutron excess shifts the mix: more nn pairs mean more np and pn final states for ν and more nn for ν̄. ν pp share: 80% in C12, O16 and Ca40; 77–78% in O18, Ar40 and Ca44; 74% in Pb208. ν̄ nn share: 77%, then 79%, then 81% in Pb208.

Lepton-side distributions

C12, Joanna’s branch, flux-averaged over the flat flux: dσ/dq0, dσ/dEμ and dσ/dcos θμ per channel, in linear and log scale.

3 · Negative weights

Individual event weights can be negative because the generator builds the five structure functions from tensor components at one sampled azimuth, as if the tensor were already azimuthally averaged. The estimator is unbiased, but single events need not be positive. The instrumented build records the ρ-transverse, π-longitudinal and interference parts of every weight separately; all three go negative on some events, so the interference term is not the only source.

Asymmetric nuclei stay within ±0.5 percentage points of C12. The only asymmetric-specific trend is in Pb208’s neutron skin, where the local ν cancelled fraction rises to 4–6%.

The flux averages include the threshold region, where the different Q values matter.

Scaling with neutron and proton number

Fitted over the seven nuclei (flux-averaged, 0.15–2 GeV): σν ∝ N1.05 and σν̄ ∝ Z1.08, close to linear in the number of nucleons the W converts (neutrons for ν, protons for ν̄). Against the other species the dependence is steeper for ν (∝ Z1.20) and flatter for ν̄ (∝ N0.95). Pb208 carries most of the lever arm.

Scaling with A

Not linear. The 2p2h rate at each point grows roughly as the local density squared, so σ ∝ A × (average density the nucleons see), and that average rises with A as the dilute surface becomes a smaller fraction of the nucleus. Gran et al. (PRD 88, 113007) find the same for the Valencia model: 2p2h “grows a bit faster than the number of nucleons”. Here σν ∝ A1.11. For the N = Z nuclei alone, which carry no neutron-excess effect, σ/A rises by 12% (ν) and 7% (ν̄) from C12 to Ca40. For ν̄ the neutron-rich nuclei pull the trend back down (Pb208 is at the C12 level per nucleon), so the overall fit is σν̄ ∝ A1.01.

Isotope comparisons

Adding neutrons should raise the channels fed by nn pairs most, those fed by np pairs modestly, and leave those fed by pp pairs flat or lower. That is what happens in every comparison (O18/O16, Ca44/Ca40, Ar40/Ca40, both beams). The isotope ratios also carry the Q differences: O16→O18 changes the ν̄ Q by −16.7 MeV. Below ω ≈ 50 MeV the shape ratios follow the sign of ΔQ exactly; above that the shapes agree within statistics.

Effect of the separate Fermi seas alone

To see the new treatment without the Q confound, each asymmetric nucleus was rerun with its local Fermi gas symmetrised: ρp = ρn = ρ/2 at every radius, with the same total density, the same Q and everything else unchanged. That control is the old single-kF physics (for N = Z it is bit-identical to the old code, §1). The ratio branch/control therefore isolates what the per-species kF does.

Statistical errors are ±1.5% on each ratio. At fixed total density a neutron excess means more nn pairs and fewer pp pairs, so the channels that start from an nn pair rise (ν np and pn, +20 to +50%) and those that start from a pp pair fall (ν̄ pn and np, −15 to −39%). The channels that start from an np pair (ν pp, ν̄ nn) change by a few percent, up for ν and down for ν̄. Ca40, N = Z but with a slightly proton-rich surface, moves the other way by 2–4%. The effect is largest near threshold and at ω ≲ 0.2 GeV, where Pauli blocking matters most.

Radial structure and the Im-clamp

The channel mix follows the local neutron excess: in Pb208’s neutron skin the ν pp share drops from 0.75 to 0.63 and the ν̄ nn share rises to 0.9; Ca40, whose protons extend slightly further because of Coulomb repulsion, moves the other way. The Im-clamp acts exactly where the analytic estimate puts it, below Eπ = EFn−EFp, and only for ν̄.

The Im-clamp in diagrams and equations

Antineutrino, nn channel: the W− turns into a π− on a neutron, and a proton absorbs the π−. How strongly the second nucleon absorbs is the imaginary part of the π− particle-hole bubble, Im U. The clamp acts there (red dot).

The bubble with separate Fermi seas, as Joanna’s branch builds it (FERMI off, so free energies ε(p) = p2/2M for both species):

np(p) = θ(kFp − |p|), nn = θ(kFn − |p|), g the spin-isospin factor. The numerator np − nn is np(1−nn) − nn(1−np): the terms with both states occupied cancel. In the code this is U(k_F^p) − C(k_F^p) + C(k_F^n).

With equal seas the second term can never satisfy the δ-function for Eπ > 0, so Im U ≤ 0. With kFn > kFp it can:

That is the process n → p + π−: an occupied neutron above the proton Fermi level drops into an empty proton state and emits the pion, so Im U > 0. ΔEF = (2702 − 2432)/2M = 7.4 MeV at the centre of Pb208 and 2.0 MeV in Ar40: the hatched edges in J(a). For neutrinos the bubble is n → p with the seas the other way round, so the window is closed in neutron-rich matter.

The absorbed-pion factor in each event’s weight (pion_inc in the code):

Π is the pion self-energy and λ = (gA/2fπ)2g′ the RPA coupling. The code sets Im UN = 0 wherever it is positive, so Pabs = 0 for that event’s charged-pion term. This removes the spurious emission, but also the genuine absorption part in the same region.

FERMI on gives each species its own constant potential:

The bubble becomes the free one evaluated at Eπ + ΔEF (in the code: Eeff = Epi − dV, dV = (kF,hole2 − kF,part2)/2M), and the emission window closes. Joanna notes that this path still needs work.

Methods

How the tests were run

Builds. origin/asymmetric-nuclei and feature/NewNuclei checked out as separate git worktrees, CMake Release. Production used a copy of the branch with three test-only additions that do not touch any weight calculation: the RNG seed from MC_SEED, an optional Q override (Q2P2H_OVERRIDE), and per-event storage of the ρ, π and interference parts of each weight. Its weights are bit-identical to the delivered binary (verified on Ar40 ν̄), and the three parts sum to the total to 3×10−11.

Samples. Flat Eν from threshold (mμ + Q) to 2 GeV, 106 stored events per nucleus and beam (C12, O16, O18, Ar40, Ca40, Ca44, Pb208), plus C12 at Re ΣΔ = −50 and +30. Old-code ν̄ events for C1 come from feature/NuFluxes (788479b). σ(E) comes from binning the flat sample: Σw over the throws in the bin. The normalisation reproduces the code’s own printed total to 3×10−6 for all 20 samples checked. 3p3h from the total-σ mode at 11 energies × 3 Re ΣΔ; the 3p3h save mode was not used (it crashes on untouched code too).

Hadron-tensor harness. Links the branch’s source files and calls the three hadron-tensor functions directly for CC and CCanti at random kinematic points drawn as in the generator. A second build of the same harness links the old sources. The Fermi-level clamp map evaluates the branch’s Lindhard functions on a grid and per event.

Separation energies. Recomputed from the AME2020 mass table (IAEA mass_1.mas20): all ten S2p/S2n values in the branch match to under 1 keV.
